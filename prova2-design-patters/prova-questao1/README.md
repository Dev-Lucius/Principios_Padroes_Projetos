# Questão 1

## Padrão Escolhido

> **Decorator**

## Justificativa

- Neste Projeto foi Usado o Padrão **Decorator**

- **Intenção**: adicionar responsabilidades a um objeto dinamicamente, envolvendo-o em outro objeto que implementa a mesma interface. É uma alternativa flexível à herança para estender comportamento.

- **Problema que resolve**: combinar funcionalidades opcionais por herança gera uma explosão de subclasses conforme descrito pelo problema
