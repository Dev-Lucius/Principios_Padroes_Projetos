# Questão 1

## Padrão Escolhido

> **Template Method**

## Justificativa

- Neste Projeto foi Usado o Padrão **Template Method**

**Intenção:** Foi escolhido a fim de definir o esqueleto de um algoritmo em uma classe base, deixando que as subclasses redefinam certos passos sem alterar a estrutura geral.
> No caso, desenvolver o corpo do Algoritmo em uma classe Base e deixar as subclasses estruturarem os passos restantes 

**Problema que resolve:** várias classes seguem o mesmo fluxo, mudando só alguns detalhes, e o código do fluxo acaba duplicado.
